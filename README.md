\# Country Capstone Project



\## Overview



This project scrapes country data from Scrapethissite, stores it in SQLite, exposes data through FastAPI APIs, exports data to CSV, and generates a Population vs Area scatter plot.



\## Technologies Used



\- Python

\- Requests

\- BeautifulSoup

\- SQLite

\- FastAPI

\- Pandas

\- Matplotlib



\## How to Run



\### Install Dependencies



bash

pip install requests beautifulsoup4 pandas matplotlib fastapi uvicorn
